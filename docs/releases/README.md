# Mössbauer DFT

Generate ORCA calculation inputs and analyze iron Mössbauer parameters through a local browser app or command line.

Download the wheel and installation guide from [Releases](https://github.com/jolayfield/mossbauer/releases). The installer includes the GUI, RDKit, chemical drawing and bundled scientific reference data. Python source is included in the wheel. Cluster access and an ORCA container are supplied by your institution.

See [INSTALL.md](INSTALL.md) for installation, personal cluster setup, manual calculation-file delivery and optional upload/agent assistance. Each scientific plan requires review and approval before input generation. The app does not submit calculations automatically.

This repository contains the application source and its releases. Personal profiles, credentials and calculation projects stay on the user's machine. License terms are in LICENSE; scientific reference data retain their cited provenance.
